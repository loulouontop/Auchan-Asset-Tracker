# Administrator guide

## Role mapping

*Administration → Profiles → [profile] → Auchan Asset Tracker*

| Role | Typical GLPI profile |
|------|----------------------|
| Central admin | Super-Admin / IT Manager |
| Location manager | Store IT manager |
| Support technician | Local tech |
| End user | Self-service |

Set **Location** for manager/tech roles.

## Thresholds

*Assets → Auchan Asset Tracker → Configuration*

- Allocation confirmation (default **5** working days)
- Transfer validation (default **7** days)
- Service max period (default **30** days)

Changes apply immediately to dashboard alerts.

## Dashboard

Global indicators (clickable), alerts, stock by location, last 15 movements.

## Final statuses

Write-off / Lost / Stolen: managers can set them; **only Central Admin** can change them or **reintroduce into stock** (pick a container).

## Reports

*Reports* menu: filter + **Export CSV**.
