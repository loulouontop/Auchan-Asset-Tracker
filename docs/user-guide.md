# End-user guide

## Dashboard

Open *Assets → Auchan Asset Tracker*.

If gear was allocated to you, you see **Pending actions** with a button to confirm.

## Confirm receipt

1. Open *Confirm receipt* (or the dashboard button).
2. For each item:
   - **Confirm receipt** → you are responsible; status **Allocated**.
   - **Did not receive** → item goes back to stock for the manager.

## My equipment

Lists gear currently with you (**Allocated** or **In service**).

## Repair

Open a normal GLPI ticket for the defective device (include serial if possible). The Asset Tracker marks it **In service** automatically when matched.
